DAKOTA — EDITABLE PORTFOLIO WEBSITE

HOW TO EDIT
1. Open index.html in a modern browser (Chrome is fine).
2. Click directly on text and type to change it.
3. Use “Save edits” to download a new HTML file containing your changes.
4. Replace the original index.html with the downloaded edited file when publishing.

IMPORTANT BEFORE PUBLISHING
- Replace YOUR-EMAIL@example.com with your real professional email.
- Add your own project screenshots and links if you have them.
- Do not claim client results or paid experience unless accurate.
- The portrait panel is a design placeholder, not a real photo. Replace it with a photo you choose if desired.
- The contact form is a visual template only and does not send messages.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in at https://github.com/ and create a public repository named dakota-portfolio.
2. Upload index.html to the repository root (not inside another folder).
3. Open Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”, select branch “main” and folder “/(root)”, then Save.
5. Wait for GitHub Pages to publish. Your URL will be https://YOUR-USERNAME.github.io/dakota-portfolio/ (replace YOUR-USERNAME with your GitHub username).
